# plotly add trace.

plotly add trace.

## Usage

``` r
lg_add_trace(data, y, y_label, yaxis = "y1", color = "#22223b")
```

## Arguments

- data:

  data frame containing the selected axis data.

- y:

  text metric to be plotted on the y-axis.

- y_label:

  text name of the metric plotted.

- yaxis:

  text axis id.

## Value

list
