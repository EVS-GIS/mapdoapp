# Prepare metrics-statistics dataframe for reactable table

Prepare metrics-statistics dataframe for reactable table

## Usage

``` r
prepare_selact_stats_for_table(
  data,
  basin_id = NULL,
  region_id = NULL,
  axis_data = NULL
)
```

## Arguments

- data:

  metrics-statistics dataframe

- type:

  type of level_type to be included in the dataframe, default is
  c("Région (total)", "Région")
